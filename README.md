# Автомойка «Блеск» — демо-лендинг

> **Демо-проект для портфолио.** Автомойки «Блеск» не существует, все контакты вымышленные
> (`+7 (000) 000-00-00`, «ул. Примерная, 1»), ссылки «позвонить» и «написать» никуда не ведут.
> Страницы закрыты от поисковиков (`noindex`).
>
> **Живая демо-версия:** https://unccule.github.io/blesk-landing/ (форма записи там честно сообщает, что заявка никуда не отправлена)

Одностраничный сайт автомойки, сделанный на чистых HTML, CSS и JavaScript, без фреймворков и сборщиков.
Собран по шаблону и правилам из моего проекта [Tonirovka 126](https://github.com/unccule/tonirovka-landing).
Заявки из формы записи на настоящем сайте приходили бы в Telegram через функцию Yandex Cloud,
поэтому токен бота не лежит на сайте.

**Чтобы сделать из демо сайт для настоящего клиента:** в `js/config.js` поставь `demoMode: false` и впиши его контакты,
удали блок `div.demo-badge` из трёх HTML-страниц и строки `<meta name="robots" content="noindex">`.

## Что внутри

- **Главный экран** с карточкой «Что нужно машине?»: посетитель выбирает задачу («Освежить», «Вернуть блеск»…),
  видит подходящую услугу и одной кнопкой записывается на неё (карточка видна на экранах от 992px).
- **Услуги и цены** (5 услуг), «Как это работает», **галерея работ** с просмотром на весь экран, частые вопросы.
- **Форма записи**: имя, телефон, услуга, дата + обязательное согласие на обработку данных.
- **Политика конфиденциальности и отдельное согласие** (152-ФЗ).
- Адаптивная вёрстка (от 320px), анимации появления, превью для мессенджеров (Open Graph).

## Структура

```
index.html            главная страница (все разделы)
privacy.html          политика обработки персональных данных
consent.html          согласие на обработку персональных данных
css/style.css         все стили (содержание — в начале файла)
js/config.js          ⭐ ВСЕ НАСТРОЙКИ: контакты, галерея, данные для политики, адрес формы
js/main.js            меню, подстановка контактов, карточка «Что нужно машине?», анимации
js/gallery.js         сетка фото и лайтбокс
js/form.js            проверка и отправка формы записи
images/               фото «О нас», иконка вкладки, картинка для превью в мессенджерах
images/gallery/       крупные фото работ (1600px), в thumbs/ — превью для сетки
server/               НЕ загружать на хостинг:
  yandex-function/      код функции для Yandex Cloud (пересылает заявки в Telegram) — основной вариант
  beget-paid/           запасной вариант на PHP — только для платного хостинга
```

## Частые правки

| Что поменять | Где |
|---|---|
| Телефон, Telegram, адрес, часы работы | `js/config.js` (часы «8–22» есть ещё в двух местах `index.html` — главный экран и плашка у фото) |
| Название/ФИО владельца, ИНН, email для политики | `js/config.js` (пока в `[скобках]` — подсвечены жёлтым) |
| Цены | `index.html`, раздел «Услуги и цены» — жёлтые `[цена]` |
| Тексты, описания услуг, вопросы | `index.html`, места помечены `ВРЕМЕННО` |
| Фото работ, подписи, порядок | `js/config.js`, блок `gallery` + файлы в `images/gallery/` |
| Цвета и шрифты | `css/style.css`, раздел 1 «Переменные» |

**Список услуг записан в нескольких местах** — строки должны совпадать буква в букву:
`<select>` в форме, `data-service` у карточек услуг и `data-pick` в карточке на главном экране (всё в `index.html`),
`SERVICES` в `server/yandex-function/index.js` (и в `server/beget-paid/send.php`, если используешь его).
Если поменять название только в одном месте, сервер отклонит заявку.

**Фото работ:** сейчас в `images/gallery/` лежат заглушки `work-01.jpg … work-08.jpg`. Положи настоящие фото
с теми же именами: крупное (по длинной стороне ~1600px) — в `images/gallery/`, квадратное превью — в
`images/gallery/thumbs/`. Потом перепиши `alt` и `caption` в `config.js`. 8 фото с одной широкой плиткой
(`wide: true`) ровно заполняют сетку. **Номера машин на фото нужно размыть.**

## Как посмотреть сайт на своём компьютере и телефоне

- **Компьютер:** открой `index.html` двойным щелчком. Форма в этом режиме работает «понарошку» (демо-режим) —
  в консоли (F12 → Console) видно, что ушло бы в Telegram.
- **Телефон:** нужен маленький локальный сервер. В папке сайта выполни `npx serve .`, затем на телефоне
  (в той же Wi-Fi сети) открой адрес вида `http://192.168.0.107:3000` — IP компьютера покажет команда `ipconfig`.
  Обрати внимание: по такому адресу форма **не** в демо-режиме, а честно покажет ошибку, пока не подключена функция.

## Как устроена отправка заявок

Всё, что лежит в папке сайта, скачивается в браузер посетителя. Если положить туда токен бота, его прочитает
кто угодно (F12) и сможет управлять ботом. Поэтому между сайтом и Telegram стоит **функция в Yandex Cloud**:
она знает токен, а посетители — нет.

```
форма на сайте ──JSON──► функция в Yandex Cloud ──токен + сообщение──► Telegram ──► владелец мойки
(хостинг)                проверяет данные,
                         хранит токен в настройках
```

Пока функция не подключена (`formEndpoint` в `config.js` пустой):
- на твоём компьютере форма работает в демо-режиме;
- на настоящем хостинге форма **не притворяется**: показывает «Не получилось отправить заявку» и ссылку на Telegram.
  Так клиент не подумает, что записался, когда заявка никуда не ушла.

Почему не PHP прямо на хостинге: на **бесплатном** тарифе Beget (правила, п. 3.12) скрипты могут обращаться
к внешним сервисам только через порт 80, а Telegram принимает запросы ботов только по HTTPS (порт 443).
На платном хостинге можно взять `server/beget-paid/send.php` (инструкция — в начале файла).

## Запуск: по шагам

### Шаг 1. Бот в Telegram
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username (должен заканчиваться на `bot`).
2. BotFather пришлёт **токен** вида `1234567890:AAH...`. Это пароль от бота — никому его не показывай
   и никуда не вставляй, кроме настроек функции (шаг 3). В файлы сайта — тоже нельзя.
3. Тот, кто будет получать заявки, открывает бота и нажимает **Start** — без этого бот не сможет ему писать.
4. Узнай **chat_id**: открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (подставь токен вместо
   `<ТОКЕН>`). В ответе найди `"chat":{"id":123456789` — это число и есть chat_id. Если ответ пустой
   (`"result":[]`), получатель ещё не нажал Start — пусть нажмёт и напишет боту любое слово, потом обнови страницу.
   Хочешь, чтобы заявки видели несколько человек, — добавь бота в группу и возьми chat_id группы (он с минусом).

### Шаг 2. Сайт на Beget
1. Зарегистрируйся на beget.com (тариф «Бесплатный»). Сайт получит адрес вида `логин.beget.tech`.
2. В панели открой **Файловый менеджер** → папка сайта → `public_html`. Удали стандартный файл-заглушку, если он есть.
3. Загрузи: `index.html`, `privacy.html`, `consent.html` и папки `css`, `js`, `images`.
   **Не загружай** папку `server` и этот `README.md`.
4. Открой сайт в браузере и скопируй из адресной строки его **точный адрес** без `/` в конце —
   например `http://blesk.beget.tech` (обрати внимание, `http` там или `https`). Он понадобится на шаге 3.

### Шаг 3. Функция в Yandex Cloud
1. Зарегистрируйся в [Yandex Cloud](https://console.yandex.cloud) и создай **платёжный аккаунт**
   (понадобится банковская карта; функции бесплатны до 1 млн вызовов в месяц).
2. Открой сервис **Cloud Functions** → **«Создать функцию»** → имя, например `blesk-form` → **«Создать»**.
3. В разделе «Последняя версия» нажми **«Создать в редакторе»**, выбери среду выполнения **Node.js**
   (версия 18 или новее), выключи добавление примеров кода → **«Продолжить»**.
4. В редакторе создай файл `index.js` и вставь в него весь код из `server/yandex-function/index.js`.
5. Заполни параметры версии:
   - **Точка входа:** `index.handler`
   - **Таймаут:** `10` секунд
   - **Память:** 128 МБ
   - **Переменные окружения:**
     - `TELEGRAM_TOKEN` — токен из шага 1
     - `TELEGRAM_CHAT_ID` — chat_id из шага 1
     - `ALLOWED_ORIGIN` — адрес сайта из шага 2. Для проверки с компьютера можно через запятую добавить
       `http://localhost:5500`, а после запуска убрать.
6. Нажми **«Сохранить изменения»**.
7. На странице функции, на вкладке **«Обзор»**, включи **«Публичная функция»** и скопируй ссылку для вызова
   вида `https://functions.yandexcloud.net/d4e...`. Эта ссылка не секретная.

### Шаг 4. Подключить форму
1. В `js/config.js` впиши ссылку из шага 3: `formEndpoint: 'https://functions.yandexcloud.net/d4e...'`.
2. Загрузи обновлённый `js/config.js` на Beget (заменить старый).
3. Отправь тестовую заявку с сайта (имя «ТЕСТ») — в Telegram должно прийти «📩 Новая заявка с сайта «Блеск»».

### Если заявка не пришла
- **На сайте «Не получилось отправить заявку»** → нажми F12 → Console. Ошибка со словом `CORS` значит,
  что `ALLOWED_ORIGIN` не совпадает с адресом сайта буква в букву (`http`/`https`, `www`, `/` в конце).
- **Логи функции:** в консоли Yandex Cloud, на странице функции → «Логи». Там видно, что ответил Telegram,
  например `chat not found` (неверный chat_id или получатель не нажал Start) или `Unauthorized` (неверный токен).
- Ответ `Invalid fields: service` — название услуги в форме не совпадает со списком `SERVICES` в функции.

- [ ] Цены вписаны вместо жёлтых `[цена]` в разделе «Услуги и цены»
- [ ] Тексты «О нас», описания услуг и ответы в FAQ сверены с владельцем (поиск по слову `ВРЕМЕННО` в `index.html`)
- [ ] Заглушки фото заменены настоящими (`images/about.jpg`, `images/gallery/…`), номера машин размыты
- [ ] В `index.html` адрес `example.ru` в Open Graph заменён на настоящий адрес сайта
- [ ] `formEndpoint` в `config.js` заполнен, тестовая заявка пришла в Telegram
- [ ] В `ALLOWED_ORIGIN` функции убран `http://localhost:5500`, если добавлял его для проверки
- [ ] Сайт проверен с телефона
- [ ] Владелец уточнил у юриста или на портале Роскомнадзора, нужно ли ему уведомление об обработке
      персональных данных и о трансграничной передаче (Telegram) — это вопрос не к коду
